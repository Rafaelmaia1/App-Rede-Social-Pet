# 🐾 PawApp — Protótipo de UI da Rede Social Pet

> Protótipo interativo de interface mobile para a rede social PawApp, desenvolvido com HTML, CSS e JavaScript puros. Funciona como GitHub Page.

## 🔗 Ver Ao Vivo

👉 **[Abrir o Protótipo](https://SEU_USUARIO.github.io/pawapp/)**

---

## 📱 Telas do Protótipo

| Tela | Descrição |
|------|-----------|
| 🌟 **Onboarding** | Apresentação do app com animações |
| 🔐 **Login** | Formulário de autenticação |
| 🏠 **Feed** | Timeline com posts, stories e botão de seguir |
| 🔍 **Explorar** | Grid de categorias, busca e veterinários próximos |
| ➕ **Novo Post** | Criação de publicação com upload e tags |
| 🔔 **Notificações** | Lista de atividades recentes |
| 👤 **Perfil** | Perfil do pet com stats, saúde e galeria |

---

## ✨ Funcionalidades Interativas

- ✅ Navegação real entre todas as 7 telas
- ✅ Curtir/descurtir posts com animação e contador
- ✅ Botão de seguir/deixar de seguir
- ✅ Filtros de categoria no Explorar
- ✅ Preview de imagem no novo post (clicável)
- ✅ Tabs no perfil (Posts / Reels / Salvos)
- ✅ Relógio real na status bar
- ✅ Drag-to-scroll nas stories
- ✅ Visibilidade do post (Público / Seguidores / Privado)
- ✅ Design responsivo (mobile e desktop)

---

## 🛠️ Tecnologias

```
pawapp/
├── index.html   → Estrutura e telas do app
├── style.css    → Design, animações e layout
├── app.js       → Navegação e interações
└── README.md    → Documentação
```

- **HTML5** — Estrutura semântica das 7 telas
- **CSS3** — Variáveis, animações, Grid, Flexbox
- **JavaScript (ES6+)** — Sem frameworks, puro vanilla
- **Google Fonts** — Fraunces + Nunito

## 🚀 Como publicar no GitHub Pages

```bash
# 1. Crie o repositório e suba os arquivos
git init
git add .
git commit -m "feat: protótipo PawApp UI"
git branch -M main
git remote add origin https://github.com/SEU_USUARIO/pawapp.git
git push -u origin main

# 2. Ative o GitHub Pages em:
# Settings → Pages → Source: main / root → Save
```

Após alguns minutos: `https://SEU_USUARIO.github.io/pawapp/`
